# Phone Search

**Phone Search** is a web application developed for the **Szczecin City Hall** that allows users to quickly search for contact information of employees and organizational units.

The application uses publicly available data from the [**Szczecin City Hall BIP (Public Information Bulletin)**](https://bip.um.szczecin.pl/chapter_131121.asp).

## Features

* Fast search through the City Hall's contact directory
* Search by employee name, department, position, room, or phone number
* Clear and simple web interface
* Data based on the official BIP website of the Szczecin City Hall

## Technologies

### Backend

* **Python**
* **FastAPI**
* **Uvicorn**

### Frontend

* **HTML**
* **Bootstrap**
* **JavaScript**

## Data Source

The application uses data published by the [**Szczecin City Hall Public Information Bulletin (BIP)**](https://bip.um.szczecin.pl/chapter_131121.asp).

The data is processed and presented in a more convenient and searchable form through the application.
